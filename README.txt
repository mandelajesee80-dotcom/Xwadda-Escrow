Xwadda Escrow - single-file site
Open index.html in a browser, or upload it to your hosting as-is.
Everything (HTML, CSS, JS, logo) is inside index.html.
The QR code library loads from cdnjs.cloudflare.com, so an internet connection is needed for QR codes.
This is a demo: deals, users and wallets are kept in memory and reset on refresh.
A real backend is needed for OTP emails, storing users/deals/wallets, live KES/USDT rates and payment confirmation.
